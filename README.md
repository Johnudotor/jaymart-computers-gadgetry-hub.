# Jaymart Computers and Gadgetry Hub

Responsive React + Vite website starter for Jaymart Computers and Gadgetry Hub.

## Included
- Responsive layout and mobile navigation
- Product-category filtering and live search
- Enquiry selection panel (no prices or stock levels are fabricated)
- Contact form validation and local email-draft handoff
- Social links supplied by the business owner
- Accessible focus states, reduced-motion support, React state/effect hooks

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Vite outputs the production site to `dist/`. Vercel can deploy this repository using the Vite preset, build command `npm run build`, and output directory `dist`.

## Before public launch
- Confirm product catalogue, stock, prices, delivery and service details.
- Replace illustrative stock photography with the official Jaymart logo, banner, and real product images.
- Add a verified WhatsApp/phone number or business email if direct messaging is desired.
- The contact form is intentionally frontend-only; it prepares an email draft and does not store or send form data to a server.
